# Purchase Order Database
- Developed a data processing and reporting solution that transformed historical purchase-order CSV files into a normalized relational database and Microsoft Access application.
- Used Python and Pandas to clean, combine, transform, and validate datasets, identifying missing, duplicate, inconsistent, and incorrectly formatted records.
- Reconciled processed data against original source files to verify accuracy and maintain data integrity.
- Designed the database schema and relationships, then built a user-facing application for searching, retrieving, and reporting on purchase-order records.
- Added document-handling functionality and used Git/GitHub for version control.

Features: UI, Queries, Reports, and Document Handling
